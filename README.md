## 📖 Overview

MathFlow is an interactive platform designed to transform mathematical learning through visual and animated solutions. It helps students understand complex mathematical concepts by breaking down problems into clear, step-by-step visual explanations.

## ✨ Features

- **Step-by-Step Animations**: Watch solutions unfold with clear, animated steps that break down complex problems
- **Visual Learning**: Convert abstract mathematical concepts into visual representations for better understanding
- **Smart Solutions**: Get instant solutions powered by advanced algorithms and AI technology
- **Clean UI**: Modern, dark-themed interface optimized for learning and reducing eye strain

## 🚀 Tech Stack

- **React 19** with TypeScript
- **Vite** for lightning-fast builds
- **TailwindCSS 4** for styling
- **React Router 7** for navigation
- **Lucide React** for beautiful icons

## 📋 Prerequisites

- Node.js (v18 or higher)
- npm or yarn

## 🔧 Installation

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/mathflow.git
   cd mathflow
   ```

2. Install dependencies
   ```bash
   npm install
   # or
   yarn
   ```

3. Start the development server
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and navigate to `http://localhost:5173`
